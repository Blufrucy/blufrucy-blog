# 流水账

事情的起因是我的华为笔记本电脑使用起来太卡了，本来Win的后台服务就不少了，现在又有华为的服务，16G内存感觉都不够使用，感觉系统好臃肿。我就想着我能不能给电脑安装上Linux（其实之前我也使用过WSL2和VM虚拟机，感觉都不怎么样），查了好多资料发现双系统的安装教程还挺多的，随机选了一个播放量多的视频就开始干了。结果因为电脑不一样，问题很多，主要都是硬件驱动什么，没办法只能AI救护车了。安装的时候还是使用的archlinux install，嗯还挺方便的就是我忘记安装系统的一些组件了，分好盘选了个KDE桌面环境就进去了。

进去的瞬间就后悔了，我还在那研究linux的键位呢，回过神才发现wifi使用不了，蓝牙也使用不了。这下好了没网络了，机智的我接上usb线使用usb共享网络，然后发现手机识别不到电脑，不给开usb共享，然后继续AI救护车，把usb修好之后连上网了，然后就开始修wifi修蓝牙，修硬件驱动，然后想着就这样了吧，重启想切回win11，结果grub没找到win的引导，我的天还回不去了。好在之前配置好了引导位置，修好之后回到win11发现win11的时间同步因为双系统出现问题了，又开始修时间，修好了想着回到archlinux学习一下吧，安装一些必要的应用浏览器什么的。不出意外又要出意外了，进入bilbil点开视频，发现没有声音。悬着的心终于死了，ok我接下来开始修声音，deepseek就开始左右脑互搏了，修了半天没修好。之后我下了一个alsamixer，通过这个软件终于解决了电脑没声音。

我以为应该没啥特别影响的我使用linux的问题，想多了。第二天先进arch里面更新一下系统的一些软件包，ok滚完看看视频吧。嗯。。。。又没声音了，根据之前的经验只要设置一个服务开机自动修改alsamixer的设置就能让电脑脱离静音，我也确实这么干了但是没生效，好吧好吧，那就每次开机手动调不就行了，这还不行吗？法克，插上耳机又没有声音了，我真服不了一点啊，开修。下这个下那个的，甚至出现插上耳机电脑扬声器有声音，拔出耳机电脑又没声音的情况，气笑了。

哈哈哈哈终于修好耳机和电脑声音了，但是精彩还在继续。我正想着开VPN代理去github上面看看有没有什么好玩的新项目呢，开了代理之后不知道干嘛又触发DNS污染了，解析网站ip出问题了，进不去甚至国内网站也访问不了，然后手动修改了DNS代理，改到阿里云DNS。一番折腾也算是能使用了，然后下了个Niri桌面环境更加好看了，果然嘉豪就得是嘉豪，KDE不过是旧时代的残党罢了

灵机一动，linux玩MC是不是很流畅，安装pcl2安装java安装mc，启动！！！ERROR程序崩溃了，好好好那修憋，M属性触发。。。。安装hmcl安装其他版本java安装其他兼容的显卡驱动。。。
哦，原来这个Niri桌面环境还比较特殊，和KDE还不一样影响了MC启动，我又尝试其他兼容的中间件启动还是无果，tmd我双系统win上面本来就下有MC我为什么不在win上面玩呢，魔怔了，可能不折腾也不知道干嘛越想越搞笑。
